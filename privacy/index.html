Данные пользователя

Политика
конфиденциальности

Упрощённая политика для текущей демонстрационной версии портфолио. Перед коммерческим запуском текст необходимо согласовать с владельцем проекта.

01

Какие данные собирает форма

Имя, контакт для связи, выбранное направление, интересующая марка или модель, ориентировочный бюджет и комментарий пользователя.

02

Для чего нужны данные

Только для ответа на запрос пользователя и обсуждения предварительного подбора автомобиля.

03

Как работает текущая версия

Это демонстрационная версия портфолио. API проверяет корректность формы и возвращает тестовый ответ. Постоянное хранение и передача данных во внешние сервисы пока не подключены.

04

Передача третьим лицам

В текущей версии данные не пересылаются в CRM, Telegram или n8n. При подключении интеграций этот раздел должен быть обновлён до публикации сайта.

05

Контакты

Контакт владельца сайта будет добавлен перед публичным запуском. До этого момента сайт не должен использоваться для реального сбора персональных данных.
